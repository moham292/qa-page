# أداة المفاتيح الستة — النسخة الأولى

ترجمة قواعد دورة "المهارات الأساسية للاستثمار والمضاربة" (خالد الرويلي) إلى كود قابل للفحص والاختبار.
**للاستخدام الشخصي والتعلم فقط — ليست توصية.**

## ما تفعله

| الملف | الوظيفة |
|---|---|
| `keys.py` | المفاتيح الستة + شروط الاختراق + الدعم/المقاومة + كشف التقاطع السلبي (الخروج) |
| `screen.py` | الفحص اليومي بعد الإغلاق: كل سهم وكم مفتاح حقق |
| `backtest.py` | محاكاة محفظة: دخول عند 6/6 (و5/6 اختيارياً)، خروج عند التقاطع السلبي، تقسيم الأجزاء الخمسة، ومقارنة بتاسي |
| `check_instructor_cases.py` | مقارنة الأداة بإجابات المدربين في الواجبات (أغسطس 2024) |
| `fetch.py` | تنزيل الأسعار من Yahoo Finance |
| `data.py` | تحميل الأسعار، القوائم المالية، والقائمة الشرعية |
| `test_keys.py` | اختبارات المنطق على بيانات مصطنعة |

## التشغيل على جهازك

```bash
python -m venv .venv && source .venv/bin/activate      # في ويندوز: .venv\Scripts\activate
pip install pandas numpy yfinance pytest
python -m pytest -q test_keys.py                        # يجب أن تنجح كلها
python fetch.py 1120 4030 1140 4200 1810 4050 4300 2382 1211 4162 --start 2018-01-01
python check_instructor_cases.py                        # أهم خطوة أولى
python screen.py --date 2024-08-06
python backtest.py
python backtest.py --allow-five      # مع استثناء 5 من 6
```

## ملفات اختيارية في `data/`

- `fundamentals.csv`: `symbol,fiscal_year,net_income,available_from` — بدونه يُعتبر المفتاح 2 متحققاً للجميع (مع تنبيه).
- `sharia.csv`: `symbol,classification,valid_from,valid_to` — بدونه الفلتر الشرعي معطّل. التصنيف من المرجع الذي تعتمده، والأداة لا تجتهد فيه.

## المعاملات التي لم تحددها الدورة (اجتهاد قابل للتعديل في `Params`)

| المعامل | القيمة الافتراضية | المعنى |
|---|---|---|
| `pivot_n` | 3 | القمة = أعلى شمعة بين 3 قبلها و3 بعدها |
| `equal_tol` | 1% | قمتان/قاعان بفرق أقل من هذا = "متساويان" ← عرضي |
| `support_tol` | 3% | "عند الدعم" = فوق الدعم بما لا يزيد عن 3% |
| `big_candle_*` | جسم ≥ 2× المتوسط، حجم ≥ 1.5× | تعريف "الشمعة الكبيرة بحجم تداول مرتفع" |
| `macd_mode` | `state` | حالة (الأزرق فوق الأحمر) — حسمتها محاضرة (8). `event` للمقارنة فقط |

القيم الصحيحة تُختار بمطابقة إجابات المدربين في `check_instructor_cases.py`، لا بالتخمين.

## قواعد حسمتها المحاضرات

- **المفتاح 5 (محاضرة 8):** جسم الشمعة كله فوق SMA 55؛ الذيل لا يُحتسب، والشمعة التي يقطع المتوسط جسمها تُعتبر تحته.
- **المفتاح 6 (محاضرة 8):** يكفي أن يكون خط MACD فوق خط الإشارة ولو حدث التقاطع منذ مدة.
- **الخروج (محاضرة 8):** "في الدخول بطبق الست مفاتيح كاملة، في الخروج بخرج على إشارة التقاطع السلبي بس".
- **تقسيم المحفظة (محاضرة 9):** خمسة أجزاء متساوية، جزء كاش للطوارئ، وأربعة للعمل ← صفقة 6/6 = 20% من رأس المال.
- **استثناء 5 من 6 (محاضرة 9، اختياري):** فقط إذا تحقق المفتاحان 1 (الاتجاه) و2 (الربح)، وبربع جزء = 5% من رأس المال. شغّله بـ `--allow-five`.
- **القمة/القاع (محاضرة 9):** صعود ← توقف عرضي شمعة أو شمعتين ← نزول (والعكس للقاع). يطابق تعريف `pivot_n` تقريباً.
- **حجم التداول (محاضرة 9):** ليس مفتاحاً؛ "كبير" = أكبر بوضوح من الحجم المعتاد قبله. يُستخدم لتأكيد الاختراق والدعم فقط.

## حدود معروفة

- **لا وقف خسارة**: الدورة (حتى المحاضرات المتاحة) لا تذكر إلا التقاطع السلبي للخروج. الاختبار يقيس "أسوأ نزول داخل صفقة" لكشف حجم الثغرة.
- **بيانات Yahoo**: قد تكون ناقصة لبعض الأسهم السعودية؛ ورموز حالات الاختبار من الذاكرة — راجعها.
- **القوائم المالية التاريخية**: تحتاج مصدراً بتواريخ الإعلان لتجنب استخدام معلومة قبل نشرها.
- **التصنيف الشرعي التاريخي**: الاختبار الصحيح يحتاج القائمة كما كانت في كل فترة، لا قائمة اليوم.
